# Release v1 - 30 augustus 2026

Status: productie-live op `https://huishouden.latero.nl`.

## Omvang

- Moderne responsive webapp voor dashboard, rapportages, transacties, sparen, budgetten, rekeningen, import, vaste lasten, categorieen, mappingregels, export en audit.
- PostgreSQL is de enige databron; CSV-fallbacks zijn niet actief.
- Sparen gebruikt de spaarrekening als bron van waarheid. Oude virtuele potjes bepalen geen primaire cijfers meer.
- Transacties gebruiken server-side filters, URL-paginering, gefilterde totalen en rustige zoek-debounce.
- Vaste-lasten-kandidaten kunnen geaccepteerd of geweigerd worden; dubbele voorstellen krijgen een attentie.
- Heigraaf-ticketbetalingen worden als `Parkeren` verwerkt, niet als brede vakantiereservering.

## Rollen

- `owner`: volledige toegang, inclusief gebruikersbeheer en restore vanuit JSON back-up.
- `admin`: financiele data beheren, importeren, exporteren en corrigeren.
- `readonly`: data bekijken en eigen wachtwoord wijzigen; geen financiele mutaties, import, export of restore.

## Releasecontrole

- Lokale releasecheck: `npm run release:check`.
- Productievalidatie: `npm run prod:validate`.
- Laatste productiecontrole op 30 augustus 2026: health, security headers, login, resetpagina en kernroutes waren groen.
- Na deploy is de productie-datacorrectie voor Heigraaf uitgevoerd en gecontroleerd.

## Gebruik

- Maak per persoon een eigen account.
- Gebruik `owner` alleen voor de eigenaar.
- Gebruik `admin` alleen voor gebruikers die mogen importeren, corrigeren of exporteren.
- Gebruik `readonly` voor meekijken.
- Download periodiek een JSON back-up via `/exporteren`.
